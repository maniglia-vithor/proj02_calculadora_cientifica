# Calculadora Científica em Python

Este projeto implementa uma **calculadora científica** em Python, capaz de realizar operações matemáticas avançadas, como funções trigonométricas, logaritmos, exponenciais e muito mais. A calculadora foi projetada para ser fácil de usar e fornecer resultados precisos para cálculos científicos.

## Funcionalidades

- **Operações básicas**: soma, subtração, multiplicação e divisão.
- **Funções trigonométricas**: seno, cosseno, tangente, etc.
- **Funções logaritmícas**: logaritmo de um número na base especificada.
- **Funções de raiz**: raiz quadrada e outras raízes n-ésimas.

## Tecnologias Usadas

- **Python 3**
- **Bibliotecas**: `math`
